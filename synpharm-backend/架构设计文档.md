## 2. 登录流程时序图

```mermaid
sequenceDiagram
    participant User as 用户
    participant Frontend as 前端
    participant Controller as AuthController
    participant Service as AuthService
    participant Factory as LoginStrategyFactory
    participant Strategy as QqEmailLoginStrategy
    participant Jwt as JwtUtils
    participant Redis as Redis
    participant MySQL as MySQL

    User->>Frontend: 点击"发送验证码"
    Frontend->>Controller: POST /api/auth/captcha/send
    Controller->>Service: captchaService.sendCaptcha(email, type)
    Service->>Redis: GET captcha:email:limit:{email}
    Redis-->>Service: 返回计数
    Service->>Redis: SET captcha:email:{email} {code} EX 60
    Service->>Service: 发送邮件
    Service-->>Controller: 返回成功
    Controller-->>Frontend: 200 OK
    Frontend-->>User: 提示"验证码已发送"

    User->>Frontend: 输入验证码，点击"登录"
    Frontend->>Controller: POST /api/auth/login
    Controller->>Service: authService.login(request, httpRequest)
    Service->>Redis: GET login:lock:{account}
    Redis-->>Service: 返回nil
    Service->>Factory: login("qq_email", request, httpRequest)
    Factory->>Strategy: login(request, httpRequest)
    Strategy->>Redis: GET captcha:email:{email}
    Redis-->>Strategy: 返回验证码
    Strategy->>Strategy: 验证验证码
    Strategy->>MySQL: SELECT * FROM sys_user WHERE email
    alt 用户存在
        MySQL-->>Strategy: 返回用户
    else 用户不存在
        Strategy->>MySQL: INSERT INTO sys_user
        MySQL-->>Strategy: 返回新用户
    end
    Strategy-->>Factory: LoginResponse
    Factory-->>Service: LoginResponse
    Service->>Jwt: generateToken(userId, email, role)
    Jwt-->>Service: 返回Token
    Service->>MySQL: INSERT INTO sys_login_log
    Service-->>Controller: LoginResponse
    Controller-->>Frontend: 200 OK {user, token}
    Frontend->>Frontend: 保存Token到localStorage
    Frontend-->>User: 登录成功
```

## 3. 预测流程时序图

```mermaid
sequenceDiagram
    participant User as 用户
    participant Frontend as 前端
    participant JwtFilter as JwtFilter
    participant Controller as PredictController
    participant Service as PredictService
    participant Factory as DataPipelineFactory
    participant Parser as SmilesInputParser
    participant Executor as DtiAlgoExecutor
    participant Client as FastApiClient
    participant FastAPI as FastAPI
    participant Formatter as JsonOutputFormatter

    User->>Frontend: 填写预测参数并提交
    Frontend->>JwtFilter: POST /api/predict/general
    Note right of Frontend: Authorization: Bearer {token}
    JwtFilter->>JwtFilter: 验证Token
    JwtFilter->>JwtFilter: 检查黑名单
    JwtFilter->>Controller: 放行请求
    Controller->>Service: predict(request, userId)
    Service->>Factory: process("smiles", "DTI", "json", inputValue, null)
    Factory->>Parser: parse(inputValue, null)
    Parser->>Parser: 解析SMILES输入
    Parser-->>Factory: ParsedInput
    Factory->>Executor: execute(parsedInput)
    Executor->>Client: predictSingle(request)
    Client->>FastAPI: POST /v1/predict/single
    FastAPI->>FastAPI: 路由匹配(algo_type=DTI)
    FastAPI->>FastAPI: 调用DTIService.predict()
    FastAPI-->>Client: AlgoResponse
    Client-->>Executor: AlgoResponse
    Executor-->>Factory: AlgoResponse
    Factory->>Formatter: format(algoResponse)
    Formatter->>Formatter: 格式化结果
    Formatter-->>Factory: PredictResultResponse
    Factory-->>Service: PredictResultResponse
    Service-->>Controller: PredictResultResponse
    Controller-->>JwtFilter: 200 OK
    JwtFilter-->>Frontend: 200 OK
    Frontend-->>User: 展示预测结果
```

## 4. 批量预测流程时序图

```mermaid
sequenceDiagram
    participant User as 用户
    participant Frontend as 前端
    participant Controller as BatchController
    participant Service as BatchProcessService
    participant ThreadPool as 线程池
    participant Factory as DataPipelineFactory
    participant Redis as Redis
    participant MySQL as MySQL
    participant FastAPI as FastAPI

    User->>Frontend: 上传CSV文件
    Frontend->>Controller: POST /api/batch/upload
    Controller->>Service: uploadBatch(file, algoType, userId)
    Service->>Service: 保存文件到uploads/
    Service->>Service: 统计CSV行数
    Service->>MySQL: INSERT INTO batch_task
    MySQL-->>Service: 返回任务ID
    Service->>Redis: SET batch:progress:{batchId} {json}
    Service->>ThreadPool: @Async submitBatchTask(batchId, algoType)
    Service-->>Controller: BatchUploadResponse
    Controller-->>Frontend: 200 OK {batchId, status: PENDING}
    Frontend-->>User: 显示任务ID和进度

    Note over ThreadPool: 异步线程开始执行
    
    ThreadPool->>Service: processBatch(batchId, algoType)
    Service->>Service: 读取CSV文件
    Service->>Service: 按CHUNK_SIZE=50分割
    
    loop 每个Chunk
        Service->>Factory: batchProcess(inputType, algoType, outputType, chunk)
        Factory->>Factory: 批量解析输入
        Factory->>FastAPI: POST /v1/predict/batch
        FastAPI-->>Factory: BatchPredictionResponse
        Factory->>Factory: 批量格式化输出
        Factory-->>Service: List<PredictResultResponse>
        Service->>Redis: SET batch:progress:{batchId} {progress: 60%}
        Service->>MySQL: UPDATE batch_task SET progress=60%
    end
    
    Service->>Service: 生成结果CSV文件
    Service->>MySQL: UPDATE batch_task SET status=2, resultPath=xxx
    Service->>Redis: SET batch:progress:{batchId} {progress: 100%}

    Note over Frontend: 用户轮询查询进度
    
    Frontend->>Controller: GET /api/batch/{batchId}
    Controller->>Service: getBatchStatus(batchId)
    Service->>Redis: GET batch:progress:{batchId}
    Redis-->>Service: 返回进度信息
    Service-->>Controller: BatchStatusResponse
    Controller-->>Frontend: 200 OK {progress: 100%, status: COMPLETED}
    Frontend-->>User: 显示完成，提供下载链接
```

## 5. 管道机制类图

```mermaid
classDiagram
    class InputParser {
        <<interface>>
        +getInputType() InputType
        +parse(inputValue: String, fileUrl: String) ParsedInput
    }

    class AlgoExecutor {
        <<interface>>
        +getAlgoType() AlgoType
        +execute(inputData: ParsedInput) AlgoResponse
        +batchExecute(inputDataList: List~ParsedInput~) List~AlgoResponse~
    }

    class OutputFormatter {
        <<interface>>
        +getOutputType() OutputType
        +format(resultData: AlgoResponse) PredictResultResponse
        +batchFormat(resultDataList: List~AlgoResponse~) List~PredictResultResponse~
    }

    class PipelineFactory {
        <<interface>>
        +process(inputType, algoType, outputType, inputValue, fileUrl) PredictResultResponse
        +batchProcess(inputType, algoType, outputType, inputs) List~PredictResultResponse~
        +supports(inputType, algoType, outputType) boolean
    }

    class DataPipelineFactory {
        -parserMap: Map~InputType, InputParser~
        -executorMap: Map~AlgoType, AlgoExecutor~
        -formatterMap: Map~OutputType, OutputFormatter~
        +process(inputType, algoType, outputType, inputValue, fileUrl) PredictResultResponse
        +batchProcess(inputType, algoType, outputType, inputs) List~PredictResultResponse~
        +supports(inputType, algoType, outputType) boolean
    }

    class SmilesInputParser {
        +getInputType() InputType
        +parse(inputValue: String, fileUrl: String) ParsedInput
    }

    class UniprotInputParser {
        +getInputType() InputType
        +parse(inputValue: String, fileUrl: String) ParsedInput
    }

    class PdbInputParser {
        +getInputType() InputType
        +parse(inputValue: String, fileUrl: String) ParsedInput
    }

    class CsvInputParser {
        +getInputType() InputType
        +parse(inputValue: String, fileUrl: String) ParsedInput
    }

    class DtiAlgoExecutor {
        -fastApiClient: FastApiClient
        +getAlgoType() AlgoType
        +execute(inputData: ParsedInput) AlgoResponse
        +batchExecute(inputDataList: List~ParsedInput~) List~AlgoResponse~
    }

    class PpiAlgoExecutor {
        -fastApiClient: FastApiClient
        +getAlgoType() AlgoType
        +execute(inputData: ParsedInput) AlgoResponse
        +batchExecute(inputDataList: List~ParsedInput~) List~AlgoResponse~
    }

    class DdiAlgoExecutor {
        -fastApiClient: FastApiClient
        +getAlgoType() AlgoType
        +execute(inputData: ParsedInput) AlgoResponse
        +batchExecute(inputDataList: List~ParsedInput~) List~AlgoResponse~
    }

    class JsonOutputFormatter {
        +getOutputType() OutputType
        +format(resultData: AlgoResponse) PredictResultResponse
        +batchFormat(resultDataList: List~AlgoResponse~) List~PredictResultResponse~
    }

    class CsvOutputFormatter {
        +getOutputType() OutputType
        +format(resultData: AlgoResponse) PredictResultResponse
        +batchFormat(resultDataList: List~AlgoResponse~) List~PredictResultResponse~
    }

    DataPipelineFactory ..|> PipelineFactory

    SmilesInputParser ..|> InputParser
    UniprotInputParser ..|> InputParser
    PdbInputParser ..|> InputParser
    CsvInputParser ..|> InputParser

    DtiAlgoExecutor ..|> AlgoExecutor
    PpiAlgoExecutor ..|> AlgoExecutor
    DdiAlgoExecutor ..|> AlgoExecutor

    JsonOutputFormatter ..|> OutputFormatter
    CsvOutputFormatter ..|> OutputFormatter

    DataPipelineFactory o-- InputParser
    DataPipelineFactory o-- AlgoExecutor
    DataPipelineFactory o-- OutputFormatter

    DtiAlgoExecutor --> FastApiClient
    PpiAlgoExecutor --> FastApiClient
    DdiAlgoExecutor --> FastApiClient
```

**设计说明**：

| 组件 | 职责 | 设计模式 |
|:---|:---|:---|
| InputParser | 解析不同类型的输入数据 | 策略模式 |
| AlgoExecutor | 执行不同算法的预测 | 策略模式 |
| OutputFormatter | 格式化不同类型的输出 | 策略模式 |
| DataPipelineFactory | 动态组合策略，执行管道 | 工厂模式 |

        bigint id PK "主键"

        bigint task_id FK "任务ID"

    }

## 8. 安全过滤链流程图

```mermaid
flowchart TD
    A[HTTP请求到达] --> B[WebAsyncManagerIntegrationFilter]
    B --> C[SecurityContextPersistenceFilter]
    C --> D[HeaderWriterFilter]
    D --> E[CorsFilter]
    
    E --> F{是否是OPTIONS请求?}
    F -->|是| G[处理预检请求]
    F -->|否| H[JwtAuthenticationFilter]
    G --> H

    H --> I{Authorization头存在?}
    I -->|是| J[提取Token]
    I -->|否| K[RequestCacheAwareFilter]
    
    J --> L{Token有效?}
    L -->|是| M[检查黑名单]
    L -->|否| N[抛出TOKEN_INVALID异常]
    
    M --> O{不在黑名单?}
    O -->|是| P[构建Authentication]
    O -->|否| Q[抛出TOKEN_BLACKLISTED异常]
    
    P --> R[设置SecurityContext]
    R --> K

    K --> S[SecurityContextHolderAwareRequestFilter]
    S --> T[AnonymousAuthenticationFilter]
    
    T --> U{无Authentication?}
    U -->|是| V[创建匿名用户]
    U -->|否| W[SessionManagementFilter]
    V --> W
    
    W --> X[ExceptionTranslationFilter]
    X --> Y[FilterSecurityInterceptor]
    
    Y --> Z{有权限?}
    Z -->|是| AA[放行到Controller]
    Z -->|否| AB[抛出AccessDeniedException]
    
    AA --> AC[Controller处理请求]
    AC --> AD[返回响应]
    
    N --> AE[结束]
    Q --> AE
    AB --> AE
    AD --> AE
```
